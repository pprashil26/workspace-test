# Workspace

A lightweight, local-first productivity system inspired by Getting Things Done (GTD).

Workspace is designed to help you:

- Capture information quickly
- Clarify next actions
- Manage commitments
- Maintain focus
- Keep reference information organized
- Stay in control of your data

Workspace intentionally prioritizes simplicity over feature bloat.

---

# Philosophy

Workspace is inspired by the principles of Getting Things Done (GTD).

The goal is not to perfectly implement GTD.

The goal is to provide a simple, fast, and practical system for capturing information, managing commitments, and maintaining focus.

Workspace emphasizes:

- Capture quickly
- Identify next actions
- Separate actions from reference material
- Review commitments regularly
- Keep the system lightweight
- Keep data under your control

If a feature adds complexity without improving execution, it probably does not belong in Workspace.

# Core Components

## Tasks

Tasks represent actions.

Examples:

- Review report
- Call vendor
- Update procedure
- Follow up audit request

Tasks support:

- Next Action
- Date
- Time
- Estimate
- Highlight
- Linked Notes
- Started status
- Waiting status
- Done status

---

## Events

Events represent commitments.

Examples:

- Team meeting
- Appointment
- Reminder
- Birthday
- School activity

Mark a task as an Event.

Events:

- Display using blue styling
- Appear in Scheduled view
- Can be filtered separately

---

## Scheduled View

Scheduled is your planning and review view.

Use it to review:

- Upcoming events
- Upcoming tasks
- Today's commitments

Available filters:

- Estimated Work
- Not Started
- Today
- Events (All / Only / Hidden)

---

## Notes

Notes store reference information.

Examples:

- Procedures
- Meeting notes
- Documentation
- Checklists

Features:

- Simple text notes
- Auto-save
- Linked Notes
- Backlinks

Create note links using:

[[Note Title]]

---

## Capture

Capture is designed for fast collection.

Capture first.
Organize later.

Examples:

- Ideas
- Follow ups
- Reminders
- Tasks to clarify later

---

## Daily Note

Daily Note provides a lightweight activity log.

Good for:

- Daily notes
- Decision history
- Work log
- Context tracking

---

## Sticky Note

Sticky Note is a temporary scratchpad.

Use it for:

- Incident numbers
- Audit IDs
- Reference data
- Temporary reminders
- Information needed right now

Features:

- Desktop side panel
- Mobile access
- Auto-save
- Refresh persistence
- Included in exports
- Included in backups
- Included in restores

Sticky Note is intentionally temporary.

Use Notes for long-term reference information.

# Recommended Workflow

## 1. Capture

Record incoming thoughts immediately.

Examples:

- Request from manager
- Audit follow-up
- New idea
- Important reminder

---

## 2. Clarify

Ask:

"What is the next physical action?"

If action is required:

- Create a Task

If information is reference:

- Create a Note

If temporary:

- Use Sticky Note

---

## 3. Organize

Place actions in an appropriate list:

- Inbox
- This Week
- Later
- Someday

Only add dates when they represent real commitments.

---

## 4. Review

Regularly review:

- Scheduled
- Waiting
- Started
- Inbox

Reviewing is where the system stays trusted.

---

## 5. Execute

Choose actions based on:

- Time available
- Energy available
- Priority
- Commitments

---

# Data Ownership

Workspace is local-first.

Your data remains in your browser.

Features include:

- Export
- Import
- Auto Backup
- Restore Previous Backup

Recommended:

1. Export regularly
2. Keep backup files
3. Use Restore Previous Backup when needed

# Design Principles

Workspace deliberately avoids:

- Complex project management
- Rich text formatting
- Folders and categories
- Multiple sticky notes
- Floating windows
- Unnecessary configuration

The aim is to stay fast, simple and focused.

---

# GTD Alignment

Workspace is:

✅ GTD-inspired

Workspace is not:

❌ A strict GTD implementation

The application takes the useful principles from GTD while remaining practical for day-to-day personal productivity.

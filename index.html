Help
Tasks
  • Use Inbox, This Week, Later and Someday.
  • Add an optional next action, date, time, highlight or linked note.
  • Use the circle to complete a task and the star to highlight it.
Notes
  • Notes contain a title and content only.
  • Type [[Note Title]] to link notes.
  • Related notes and backlinks appear in the note editor.
Data
  • All data stays in this browser.
  • Export regularly and use Import to restore a backup.
